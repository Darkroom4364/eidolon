# Code of Conduct

Eidolon contributors and maintainers must keep project spaces professional,
respectful, and safe.

## Expected Behavior

- Critique ideas and code without attacking people.
- Respect differing experience, backgrounds, and viewpoints.
- Protect personal information, credentials, target data, and private reports.
- Keep all security work inside owned or explicitly authorized environments.
- Accept correction and focus discussion on reproducible evidence.

Harassment, threats, discrimination, doxxing, sexualized conduct, sustained
disruption, or publishing another person's private information are not
acceptable.

## Enforcement

Maintainers may edit or remove content, reject contributions, or temporarily
or permanently restrict participation when this policy is violated.

Report conduct concerns through
[GitHub private vulnerability reporting](https://github.com/Darkroom4364/eidolon/security/advisories/new).
If that channel is unavailable, open an issue containing only a request for a
private contact channel. Do not publish sensitive details.

Maintainers will limit disclosure to what is necessary to investigate and act.
