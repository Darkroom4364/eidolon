# Name

## Decision

The project name is:

```text
Eidolon
```

`Agentwall` is now the legacy codename.

## Why Eidolon

An eidolon is a phantom, image, apparition, or constructed likeness.

That maps directly to the technical idea:

```text
show hostile autonomous agents a controlled likeness of the target,
then trace whether they act on that synthetic evidence
```

The name fits the project better than `Agentwall` because Eidolon is not a generic wall/firewall metaphor. It points to controlled perception, false surfaces, and traceable phantom reality.

## Positioning

Short:

```text
Eidolon: controlled reality for autonomous cyber agents.
```

Precise:

```text
Eidolon is target-side active defense for autonomous pentesting agents.
```

Research-oriented:

```text
Eidolon measures and diverts agentic reconnaissance through causal bait and black-box trace reconstruction.
```

## Naming Constraints

Avoid positioning Eidolon as:

- an AI firewall
- an agent firewall
- a generic honeypot
- a generic deception platform
- an anti-crawler maze

Those categories are crowded and would blur the project.

Use:

```text
target-side active defense
causal bait
black-box trace reconstruction
controlled reality
autonomous pentesting agents
```
