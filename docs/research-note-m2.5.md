# M2.5 Lab-Only V1-Candidate Research Note

This note is a Lab-only v1-candidate artifact for M2.5 micro controlled reality. It is not a public v1 note, production-readiness statement, or deployment claim.

## Claim Under Test

Eidolon can route one qualifying Lab session into one synthetic controlled-reality branch after documented bait-derived behavior, while keeping protected upstream state unchanged.

The claim is limited to:

- an owned loopback Lab
- the synthetic demo target
- one configured decoy admin/API branch
- auditable policy-state transition events
- no-write behavior for bait-derived and decoy write paths

## Required Evidence

The M2.5 candidate should include:

- event log showing prior `bait_exposed` and matching `bait_action_observed`
- event log showing the controlled-reality policy-state transition and reason
- event log showing decoy branch routing and response ownership
- evidence that bait-derived writes and decoy writes were not forwarded to the protected upstream
- event log showing `reality_escape_attempt` when a contained session requests outside the configured branch
- negative controls for wrong marker, wrong session, ordinary traffic, and emergency disable
- dwell time, action-depth, and branch-count measurements for the controlled-reality branch
- configured max depth, tarpit delay, and retry-after behavior for rate-limited containment

## Safety Boundary

All controlled-reality data must be synthetic, non-sensitive, non-exploitable, and safe if copied, indexed, logged, or disclosed.

The Lab candidate must not use real secrets, customer data, real internal hostnames, production services, external callbacks, or exploit instructions that improve third-party capability.

## Non-Claims

M2.5 does not claim:

- autonomous-agent identity
- broad containment
- adaptive bait policy
- public-v1 readiness
- production readiness
- safe deployment outside the owned loopback Lab

## Open Risks

- False confidence if controlled-reality entry is triggered without the documented same-session evidence.
- Accidental leakage if synthetic data is derived from real customer, service, or infrastructure names.
- Unsafe behavior if emergency disable does not stop intervention on the next request.
- Overclaiming if one decoy branch is described as general containment.
